# Ledge

Ledge is a free Mac player for YouTube Music. It hangs in the notch.

The site is this folder. Version 1.0 is in [`download/Ledge-1.0.zip`](download/Ledge-1.0.zip).

- macOS 13 or later
- Apple silicon
- Google Chrome

macOS blocks apps that are not notarized. After unzipping, move Ledge to Applications, then Control-click it and choose Open.
